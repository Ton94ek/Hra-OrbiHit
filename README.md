# Orbit Arena - Tournament Master

## Spuštění

1. Spusťte lokální server:

```bash
python3 -m http.server 8000
```

2. Otevřete v prohlížeči:

```
http://localhost:8000/index.html
```

## Ovládání

- Každý hráč používá nastavenou klávesu pro přichycení/odpojení lana.
- `P` pozastaví/odpozastaví hru.
- `Esc` otevře menu pauzy.
